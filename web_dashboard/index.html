Berlaku untuk pekerjaan baru

Parameter SuGaR mengacu ke README dan train.py resmi. Pengaturan data/COLMAP merupakan protokol eksperimen terpisah.

Acuan: README SuGaR · train.py resmi. Preset hanya mengubah parameter SuGaR; resolusi dan COLMAP tetap sesuai pilihanmu. dn_consistency direkomendasikan repo terbaru; tabel paper memakai konfigurasi regularisasi lain.

Memuat perkiraan resolusi...
Sesuaikan ukuran foto acuan untuk perkiraan

Hanya untuk perkiraan. Ukuran aktual mengikuti foto hasil undistorsi.

Rasio gambar dipertahankan tanpa memperbesar foto. Kedua metode memakai pengaturan ukuran training dan evaluasi yang sama.

Memeriksa build COLMAP server...

Sequential memerlukan nama file yang terurut mengikuti pengambilan, misalnya frame_00001.jpg. Mode GPU mempercepat SIFT; mapper masih dapat memakai CPU.

Satu pekerjaan pada satu waktu. Baseline 3DGS memakai 30.000 iterasi. Perubahan resolusi/COLMAP memicu ulang tahap yang terdampak.

Antrean mencegah pekerjaan berjalan bersamaan. Kebutuhan memori satu scene tetap perlu diuji; preset belum merupakan benchmark dataset kamu.

Evaluasi geometri menghitung Chamfer distance serta Precision, Recall, dan F1 pada ambang 2 cm dan 5 cm. Simpan ground truth pada ground_truth/lidar.ply, isi skala model, lalu pilih Evaluasi LiDAR di kartu model.

Metrik geometri menilai ketepatan dan cakupan titik terhadap LiDAR, bukan klasifikasi delapan kelas togog. Evaluasi visual PSNR, SSIM, dan LPIPS dapat dijalankan tanpa LiDAR.

Pengaturan utama tersimpan di browser. Perubahan berlaku untuk pekerjaan baru; antrean yang sudah ada tetap memakai konfigurasi sebelumnya.
