Evaluasi geometri dengan LiDAR

Klik Antrekan Model di kanan atas, lalu pilih Evaluasi geometri. Satuan LiDAR disimpan per model pada popup.

Sistem dapat mencari skala, posisi, dan rotasi secara otomatis. Pilih satuan koordinat file LiDAR yang sudah diperiksa: meter, sentimeter, atau milimeter. Faktor skala manual tersedia sebagai pilihan lanjutan.

Chamfer, Precision, Recall, dan F1 dihitung bersama pada ambang 2 cm dan 5 cm. LiDAR dan rekonstruksi harus mencakup objek yang sama. Periksa overlay penyelarasan sebelum menggunakan skor untuk skripsi. Evaluasi visual dapat dijalankan tanpa LiDAR.

Acuan konfigurasi dan catatan penelitian

Preset berasal dari README SuGaR dan train.py resmi. Preset mengubah mesh, Gaussian per segitiga, refinement, dan regularisasi. Resolusi foto serta COLMAP mengikuti pilihan terpisah.

dn_consistency direkomendasikan repo yang diperbarui; tabel paper memakai regularisasi lain. Parameter mesh upstream bernama n_vertices_in_mesh, tetapi extractor meneruskannya sebagai budget decimation segitiga. Preset belum merupakan benchmark dataset penelitian ini. Foto acuan hanya menghasilkan perkiraan di layar, bukan mengubah file input.

Nilai utama tersimpan di browser dan disalin saat model masuk antrean. Mengubah isian tidak mengubah pekerjaan yang sudah menunggu atau berjalan. Satuan LiDAR dan penyelarasan disimpan per model melalui popup antrean.
